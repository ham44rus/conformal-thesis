# 等角予測による分布によらない予測区間

**卒業研究 2026年度（R08）後期 ／ 東京理科大学 理学部第一部 応用数学科 黒沢研究室**

予測モデルにもデータ分布にも仮定を置かず、有限個のデータだけで被覆率 $1-\alpha$ を
保証する予測区間（conformal prediction）を、定理の証明・シミュレーション・実データの
3層で扱う。

---

## 研究の問い

| | 問い | 対応する実験 |
|---|---|---|
| **RQ1** | 有限標本被覆保証は実際にどの程度正確に成り立つか。理論の上下界 $1-\alpha \le P \le 1-\alpha+1/(n+1)$ を実測は挟めるか | E1 |
| **RQ2** | 予測区間の**幅**は、下敷きモデルと非適合度スコアの選び方でどう変わるか | E2, E5, E6 |
| **RQ3** | 保証が壊れるのはどんなときか。条件付き被覆と交換可能性の破れという2つの限界 | E3, E4 |

---

## クイックスタート

```bash
pip install -e ".[dev]"

make test      # 検証テスト（実装を信用する唯一の根拠）
make e1        # 実験E1を実行 -> results/*.csv
make figures   # csv から figures/*.pdf を再生成
```

`make e1` は約10秒、`make test` は約1分で終わる。

### 現状の実行結果（E1）

| n | α | 下界 | 実測 | 上界 | 判定 |
|---|---|---|---|---|---|
| 20 | 0.10 | 0.9000 | 0.9029 | 0.9476 | OK |
| 100 | 0.10 | 0.9000 | 0.9010 | 0.9099 | OK |
| 500 | 0.10 | 0.9000 | 0.8996 | 0.9020 | OK |
| 2000 | 0.10 | 0.9000 | 0.8994 | 0.9005 | OK |

被覆率の経験分布は理論の $\mathrm{Beta}(n+1-l,\, l)$ と一致する（`figures/fig_e1_coverage_beta_alpha10.pdf`）。

## 設計上の約束

1. **実験の実行と作図を分離する。** 実験は csv を吐き、図は csv から作る。
   実験を回し直さずに図だけ直せる状態を保つ（締切前に効く）。
2. **仕様書を書いてから実装する。** `specs/` に仕様がない実験は作らない。
   仕様書はそのまま卒論第5章の下書きになる。
3. **テストは理論から書く。** 「実装がこう動く」ではなく「理論がこう言う」で書く。
   これが生成AIの書いたコードを信用できる唯一の根拠になる。
4. **共形分位点は `ceil((n+1)(1-alpha))`。** `np.quantile` を使わない。
   詳細は `CLAUDE.md`。
