# 実験仕様書

**実装の前にここを書く。** 仕様書なしで Claude Code にコードを書かせない。

理由は2つ：

1. この粒度の仕様書があると生成コードがほぼ一発で通る。手戻りが消える。
2. **仕様書がそのまま卒論 第5章の下書きになる。** 仕様を書く時間は執筆時間の前借りであって、
   追加コストではない。

新しい実験を作るときは `TEMPLATE.md` をコピーして使う。
