# 実験仕様書

**実装の前にここを書く。** 仕様書なしで Claude Code にコードを書かせない。

理由は2つ：

1. この粒度の仕様書があると生成コードがほぼ一発で通る。手戻りが消える。
2. **仕様書がそのまま卒論 第5章の下書きになる。** 仕様を書く時間は執筆時間の前借りであって、
   追加コストではない。

新しい実験を作るときは `TEMPLATE.md` をコピーして使う。

## 仕様書に必ず書くこと（Claude Code が実装できない＝仕様の穴）

過去に実装を止められた項目。**新しい仕様書を書いたら、この6点が埋まっているか確認する。**

1. **試行ごとに何を引き直し、何を固定するか**（学習集合／モデル／較正集合／テスト集合）
2. **規模のパラメータ**（n_cal、alpha、試行数、テスト集合サイズ）
3. **どのモデル・手法を含めるか**（境界ケースを含めるかの判断も）
4. **検証基準の操作的な定義**（「ほぼ同一」を何の数値で判定するか。閾値まで書く）
5. **出力 csv の列**
6. **内部乱数を持つ手法の random_state を seed からどう導出するか**（再現性ルールのため）
