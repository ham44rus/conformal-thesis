# E1: 有限標本被覆保証の検証

対応：卒論 第5章 E1 の節（`sec:e1`）／ 実装 `experiments/e1_coverage.py`

## 目的

分割等角予測の被覆率が理論の上下界

    1 - alpha  <=  P(Y in C(X))  <=  1 - alpha + 1/(n+1)

に入ることを確認し、さらに被覆率の分布が

    Beta(n+1-l, l),   l = floor((n+1) * alpha)

と一致することを示す（Vovk 2012）。

## データ生成過程

`src/conformal/datasets.py: homoscedastic`

    X ~ Uniform(0,1)^5
    Y = X1 + sin(2*pi*X2) + N(0, 0.5^2)

## 手続き

1. 学習用 500 点でリッジ回帰（alpha=1.0）を学習する。
   **学習データとモデルは全試行で固定**する（キャリブレーション集合の効果だけを見るため）。
2. テスト集合 100,000 点を生成し、絶対残差を先に計算しておく。
   被覆率は `mean(残差 <= q)` で評価できるので、試行ごとにモデルを呼ばずに済む。
3. 試行 r = 1..1000 について：
   a. キャリブレーション n 点を新規生成し、絶対残差スコアから q を計算
   b. 被覆率と区間幅（= 2q）を記録
4. n in {20, 50, 100, 500, 2000}, alpha in {0.05, 0.10, 0.20} の全組合せ

## 出力

- `results/e1_coverage.csv` : 列 = [n_cal, alpha, trial, coverage, width]
- `results/e1_summary.csv`  : (n_cal, alpha) ごとの要約。理論の上下界、平均被覆率の 95% 区間、
  Beta 分布のパラメータと KS 検定の p 値、平均区間幅

  平均被覆率 m の区間は `m ± 1.96 * SE`、SE は 2 成分の合成

      SE = sqrt( SE_trial^2 + p(1-p)/N ),   SE_trial = SD_trial / sqrt(R),   p = m,  N = 100,000

  で計算する（列 `se_trial`, `se_test`, `ci_lo`, `ci_hi`）。SE_trial は較正集合の引き直しによる
  試行間のばらつきで試行数 R で薄まるが、テスト集合成分 p(1-p)/N は R で割らない。
  Clopper–Pearson 区間は使わない：テスト集合を全試行で固定しているため、R×N 個の判定は
  独立な二項試行ではなく、CP は区間を過小に見積もる（後述「被覆率が経験推定であること」第 4 項と
  同じ理由。CLAUDE.md「報告の作法」の「テスト集合間」）。

## 検証（この実験が正しく走ったと判断する基準）

- 各 (n, alpha) で `coverage` の平均が `[1-alpha, 1-alpha+1/(n+1)]` に入る（`in_bounds` 列が True）
- `coverage` の経験分布と理論 Beta 分布の KS 検定 p 値 > 0.01

## 実行結果（seed 既定、`results/e1_summary.csv`）

- `in_bounds`：15 セルすべて True。
- KS 検定（p > 0.01）：**15 セル中 2 セルが基準を満たさなかった。** n = 2000 の α = 0.05（p = 0.00017）と
  α = 0.10（p = 0.00096）。他の 13 セルは p ≥ 0.12。基準は変更しない。

**原因の仮説（固定テスト集合による共通のずれ）.** 被覆率は固定した N = 100,000 点のテスト集合で
推定しているので、その集合固有のずれが全試行に共通に乗る（下記「被覆率が経験推定であること」の第 4 項）。
ずれの大きさは Beta(k, n+1−k) の SD の約 √((n+2)/N) 倍で、n = 2000 では約 0.14 SD である。
分布全体が 0.14 SD 平行移動すると、KS 統計量は理論分布の密度が最大の点で最大になり、
標準正規に近い形では約 0.4 × 0.14 ≈ 0.056 になる。一方 R = 1000 での p = 0.01 の棄却点は
約 1.63/√1000 ≈ 0.052 なので、**このずれは R = 1000 の KS 検定で検出できる大きさである。**
n ≤ 500 では比が 0.07 以下で、KS 統計量の期待される増分は棄却点を下回る。つまり棄却は
分布の形の違いではなく、固定テスト集合による推定のバイアスによると考えられる。実装の誤りではない
（`tests/test_quantile_index.py`、`tests/test_coverage_theory.py` は通っている）。

**検証方法（再評価）.** この仮説が正しければ、テスト集合を十分大きくして共通のずれを小さくすれば
KS 検定は通るはずである。E1 と同じ学習済みモデル・同じ試行の共形分位点 q̂ を使い、
E1 のテスト集合とは別の seed で作った 4,000,000 点の独立なテスト集合（E1b の「真値」と同じ作り方）で
各試行の被覆率を測り直し、15 セルの KS p 値を再計算する。比 √((n+2)/N) は n = 2000 で約 0.022
になる。手順と結果は下記「再評価」を参照。

## 既知の注意点（論文の第5章に書く価値がある）

**テスト集合が有限だと、被覆率の推定に二項ノイズが上乗せされる。**
見たいのはキャリブレーション集合を固定したときの「真の」条件付き被覆率（= Beta に従う量）
なので、テスト集合が小さいと分散が理論より大きくなり、**実装が正しくても KS 検定が棄却される**。

実際、試作段階でテスト集合 2,000 点では p = 0.003 で棄却され、200,000 点にしたら p = 0.37 で
通った。逆に n が大きい領域（n = 2000）では Beta 分布自体が細くなるため、
テスト集合 100,000 点でも二項ノイズの相対的な影響が残り、KS の p 値が小さくなることがある。

**「理論と合わない」と思ったとき、実装のバグなのか推定の分散なのかを切り分ける必要がある。**
この議論は第5章に1段落として書くこと。切り分けの方法は以下：

- テスト集合サイズを変えて KS の p 値がどう動くか見る（分散の問題なら改善する）
- `in_bounds`（平均被覆率が上下界に入るか）は二項ノイズに鈍感なので、こちらは通るはず
- `tests/test_quantile_index.py` が通っているか（バグなら必ず落ちる）

## 被覆率が経験推定であること（E1 の節 `sec:e1` の本文に入れる内容）

定理 3.18（`thm:cond-coverage-beta`）の被覆率 Cov = F_d(q̂) は真の分布関数の値であり、
E1 で観測しているのはそれ自体ではない。E1 の節（`sec:e1`）では次の 4 点を明記する。

1. **観測量は推定値.** 各試行で記録する `coverage` は、固定した 100,000 点のテスト集合による
   推定値 mean(残差 <= q̂)（`eq:coverage-rate` の経験的な被覆割合）であり、Cov そのものではない。
2. **d を固定している.** 学習データとモデルは全試行で固定している（学習用データ d を 1 つ固定）。
   したがって検証しているのは、定理 3.18 の証明のうち **d で条件付けた段階の主張**
   （d を固定しても Cov ~ Beta(k, n+1-k)）であり、d の引き直しは含まない。
3. **推定誤差の大きさ.** テスト点ごとの推定誤差の SD は sqrt(p(1-p)/N)（p = k/(n+1)、N = 100,000）。
   Beta(k, n+1-k) の SD は sqrt(k(n+1-k)/((n+1)^2(n+2))) なので、p を Cov の期待値 k/(n+1) で
   置いたとき、比は厳密に sqrt((n+2)/N) になる（p(1-p) が約分される。実際の p は試行ごとに
   揺れるが、その揺れの幅は Beta の SD 程度なので比はほぼ変わらない）。
   実験格子の全セルでの値は下表のとおり。最大の n = 2000 で約 0.14。
4. **固定テスト集合は共通のバイアス.** テスト集合を固定しているので、この推定誤差は試行間で共通で
   あり、ヒストグラム全体がわずかに横にずれる形で現れる。試行数を増やしても消えない
   （CLAUDE.md「報告の作法」の「テスト集合間」成分。`e1_summary.csv` の `se_test` 列）。

## 再評価：大きな独立テスト集合による KS 検定（`experiments/e1_reeval_large_test.py`）

- 入力：`results/e1_coverage.csv`（試行ごとの `width` = 2 q̂ から q̂ を復元する）。
  試行の再実行はしない。
- 学習済みモデルは E1 と同じ手順・同じ seed で再構成する（`rng` の引き順が E1 と同じなので、
  学習集合とモデルは E1 と一致する）。
- テスト集合：E1 のテスト集合を引いた後、さらに E1 の試行ループ分の乱数を消費せず、
  **別の seed**（`--test-seed`、既定 20260922）で 4,000,000 点を独立に生成する。
- 各 (n, α, trial) について Cov = mean(残差 ≤ q̂) を再計算し、セルごとに KS p 値を出す。
- 出力：`results/e1_reeval_large_test.csv`（列 = [n_cal, alpha, n_test, ks_pvalue_original,
  ks_pvalue_reeval, coverage_mean_original, coverage_mean_reeval, se_test_reeval]）。
  既存の csv は変更しない。
- 同じ seed で 2 回実行して csv が一致すること（CLAUDE.md 再現性ルール）。
- 結果は実装後にここへ追記する。
