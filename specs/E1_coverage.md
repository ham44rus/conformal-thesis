# E1: 有限標本被覆保証の検証

対応：卒論 第5章 5.2節 E1 ／ 実装 `experiments/e1_coverage.py`

## 目的

分割等角予測の被覆率が理論の上下界

    1 - alpha  <=  P(Y in C(X))  <=  1 - alpha + 1/(n+1)

に入ることを確認し、さらに被覆率の分布が

    Beta(n+1-l, l),   l = floor((n+1) * alpha)

と一致することを示す（Vovk 2012）。

## データ生成過程

`src/conformal/datasets.py: homoscedastic`

    X ~ Uniform(0,1)^5
    Y = X1 + sin(2*pi*X2) + N(0, 0.5^2)

## 手続き

1. 学習用 500 点でリッジ回帰（alpha=1.0）を学習する。
   **学習データとモデルは全試行で固定**する（キャリブレーション集合の効果だけを見るため）。
2. テスト集合 100,000 点を生成し、絶対残差を先に計算しておく。
   被覆率は `mean(残差 <= q)` で評価できるので、試行ごとにモデルを呼ばずに済む。
3. 試行 r = 1..1000 について：
   a. キャリブレーション n 点を新規生成し、絶対残差スコアから q を計算
   b. 被覆率と区間幅（= 2q）を記録
4. n in {20, 50, 100, 500, 2000}, alpha in {0.05, 0.10, 0.20} の全組合せ

## 出力

- `results/e1_coverage.csv` : 列 = [n_cal, alpha, trial, coverage, width]
- `results/e1_summary.csv`  : (n_cal, alpha) ごとの要約。理論の上下界、Clopper–Pearson 区間、
  Beta 分布のパラメータと KS 検定の p 値、平均区間幅

## 検証（この実験が正しく走ったと判断する基準）

- 各 (n, alpha) で `coverage` の平均が `[1-alpha, 1-alpha+1/(n+1)]` に入る（`in_bounds` 列が True）
- `coverage` の経験分布と理論 Beta 分布の KS 検定 p 値 > 0.01

## 既知の注意点（論文の第5章に書く価値がある）

**テスト集合が有限だと、被覆率の推定に二項ノイズが上乗せされる。**
見たいのはキャリブレーション集合を固定したときの「真の」条件付き被覆率（= Beta に従う量）
なので、テスト集合が小さいと分散が理論より大きくなり、**実装が正しくても KS 検定が棄却される**。

実際、試作段階でテスト集合 2,000 点では p = 0.003 で棄却され、200,000 点にしたら p = 0.37 で
通った。逆に n が大きい領域（n = 2000）では Beta 分布自体が細くなるため、
テスト集合 100,000 点でも二項ノイズの相対的な影響が残り、KS の p 値が小さくなることがある。

**「理論と合わない」と思ったとき、実装のバグなのか推定の分散なのかを切り分ける必要がある。**
この議論は第5章に1段落として書くこと。切り分けの方法は以下：

- テスト集合サイズを変えて KS の p 値がどう動くか見る（分散の問題なら改善する）
- `in_bounds`（平均被覆率が上下界に入るか）は二項ノイズに鈍感なので、こちらは通るはず
- `tests/test_quantile_index.py` が通っているか（バグなら必ず落ちる）
