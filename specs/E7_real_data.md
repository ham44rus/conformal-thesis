# E7: 実データ解析（UCI の公開データ 3 件）

対応：卒論 第6章 実データ解析（`sec:real-data`）
／ 実装 `experiments/e7_real_data.py`（3 手法の作り方は `experiments/e3_conditional.py` の `fit_all`・`intervals` を共有）
／ データの入手方法 `docs/データの入手方法.md`

## 目的

UCI の公開データ 3 件で、分割等角予測の 3 手法（(a) 絶対残差、(b) 正規化残差、(c) CQR）の
周辺被覆率、層別被覆率、平均の幅を測る。人工データ（E2・E3、`sec:e3`）で見た性質が実データでも再現するかを見る。

## 理論

データ集合を固定すると、行をランダムに並べ替えて分けた較正用とテスト点は交換可能である。
よって定理 `thm:coverage` の周辺被覆保証が、分割の乱数についての確率として成り立つ：

    1 - alpha  <=  P(Y_test ∈ C(X_test))  <=  k / (n_cal + 1)       k = ceil((n_cal+1)(1-alpha))（eq:khat）

上界（`cor:upper`）はスコアに同点が無いことを仮定する。Superconductivity は同じ行の重複があり、
同点が起こりうるので、上界は合否の基準にせず数値を報告する。

時間順の分割では交換可能性が成り立たないかもしれない（`rem:exch-violation`、E4 とつながる）。
したがって補足分析には保証が無く、合否の基準にしない。

## 手続き

### 主分析：ランダム分割（3 データ共通）

データごと・試行 `r = 1..100` ごとに：

1. モデルの `random_state` を 4 つ引く（下の「乱数の導出」）。
2. 行をランダムに並べ替え、学習用・較正用・テスト用に分ける。3 つが重ならないことを `assert` で確かめる。
3. 学習用だけで 3 手法の下敷きを作る（`experiments/e3_conditional.py: fit_all`。E3 と同じ）：
   - 予測モデル `f_hat`：`GradientBoostingRegressor`（既定値）
   - (a) 絶対残差 `|y - f_hat(x)|`（`eq:score`）
   - (b) 正規化残差 `|y - f_hat(x)| / (sigma(x) + eps)`（`eq:score-normalized`、`eps = 1e-8`）。`f_hat` は (a) と共有。
     `sigma` は `fit_sigma`：学習用の K=5 の out-of-fold 残差の絶対値を勾配ブースティング（既定値）で回帰し、
     out-of-fold 残差の 5% 分位点を下限にする（E3 と同じ規約）
   - (c) CQR（`eq:cqr-score`）：`fit_quantile_pair` で水準 0.05 と 0.95 の分位点回帰（勾配ブースティングの pinball 損失、既定値）
4. 較正用のスコアから `conformal_quantile`（`k = ceil((n_cal+1)(1-alpha))`）で `q_hat` を求め、テスト用で区間を作る
   （`intervals`。(b) は `f_hat(x) ± q_hat (sigma(x) + eps)`、(c) は `[q_lo(x) - q_hat, q_hi(x) + q_hat]`）。
5. 層：較正用の予測値 `f_hat(x)` から `bin_edges_from_quantiles` で 5 分位の境界を作る
   （記述統計としての分位点。共形分位点ではない）。最下端は `-inf`、最上端は `+inf` にして、すべてのテスト点がどこかの層に入るようにする。
   テスト点を `f_hat(x)` で層に分け、層ごとの被覆率を求める。層は `f_hat` だけで決まるので 3 手法で同じ。
6. 記録（手法ごと）：周辺被覆率、平均の幅、層別被覆率、層別被覆率の幅（層の被覆率の最大 − 最小）、`q_hat`。

### 補足分析：Bike Sharing の時間順の分割（1 回だけ）

1. `instant`（時間の順番）で並べ、最初の 50% を学習用、次の 25% を較正用、最後の 25% をテスト用にする（点数は主分析と同じ 8,690・4,345・4,344）。
   分割に乱数は使わない。
2. 3 手法を主分析と同じ手順で作り、周辺被覆率と Clopper–Pearson 95% 区間（`clopper_pearson`。1 回の適用なので）、
   平均の幅、層別被覆率を記録する。

### 乱数の導出

`np.random.default_rng(seed).spawn(4)` で独立な乱数列を 4 本作り、
Airfoil、Superconductivity、Bike Sharing のランダム分割、Bike Sharing の時間順分割に、この順で 1 本ずつ割り当てる
（データごとに乱数列を分けるので、あるデータの処理が他のデータの乱数に影響しない）。

ランダム分割では、各データの乱数列から試行 1, 2, …, 100 の順に、試行ごとに

1. モデルの `random_state`（整数）を `f_hat, sigma, cqr_lo, cqr_hi` の順に 4 つ（E3 の `MODEL_SEED_KEYS` と同じ順。
   `sigma` の値は out-of-fold の組分けにも使う。E3 と同じ）
2. 0..n-1 の並べ替え 1 つ

を引く。時間順分割では、4 本目の乱数列からモデルの `random_state` 4 つを同じ順に引く。

  （3 データ × 100 試行 × 3 手法 = 900 行）。テスト点が 1 つも入らない層は空欄（NaN）。
- `results/e7_summary.csv`：データ×手法ごとに 1 行（9 行）。列 = `dataset, method, n_total, n_train, n_cal, n_test, k, alpha, n_trial,
  coverage_mean, coverage_sd, se, ci_lo, ci_hi, theory_lo, theory_hi, width_mean, width_sd, strata_range_mean, strata_range_sd, cov_bin1..cov_bin5`

      se = coverage_sd / sqrt(R)
      ci_lo, ci_hi = coverage_mean ± 1.96 se
      theory_lo = 1 - alpha,  theory_hi = k / (n_cal + 1)

  テスト集合は試行ごとに引き直すので、全試行に共通のテスト集合バイアスは無い。SE は試行間 SD だけから作る
  （CLAUDE.md「報告の作法」の試行間の行）。`width_*`・`strata_range_*` は試行ごとの値の平均と SD（ddof=1）。
  `cov_bin*` は層別被覆率の試行平均（空の層は除く）。
- `results/e7_timesplit.csv`：Bike の時間順分割、手法ごとに 1 行（3 行）。列 = `method, n_train, n_cal, n_test, k, coverage, cp_lo, cp_hi, mean_width, cov_bin1..cov_bin5`

同じ seed で 2 回実行して csv が完全に一致すること。実行時間は csv に入れない（画面に出し、下の「実行結果」に書く）。

## 検証（実行前に決めた。結果を見てから変えない）

- **V1（周辺被覆の下限）**：ランダム分割のすべてのデータ×手法で `coverage_mean >= 1 - alpha - 3*se`。
- **V2（分割とデータ）**：学習用・較正用・テスト用が重ならない（`assert`）。zip の sha256 が一致する。
- 合否の基準にせず数値を報告するもの：
  - 上限 `k/(n_cal+1)` との比較（Superconductivity は同じ行の重複があり同点が起こりうる）
  - 層別被覆率の幅が、絶対残差より正規化残差・CQR で小さいか
  - 平均の幅の手法間の差
  - Bike の時間順分割の被覆率
- 基準を満たさなかった場合は、基準を変えずに事実を「実行結果」に書く。
