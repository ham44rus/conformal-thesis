# E3: 異分散データと条件付き被覆の破綻 ★本論文の見せ場

対応：卒論 第5章 5.7節 ／ 実装 `experiments/e3_conditional.py`（未実装・W7で作る）

## 目的

周辺被覆が `1-alpha` を満たしていても、**部分集団ごとの被覆は大きく割れる**ことを示す。
そのうえで、正規化残差スコアと CQR がこれをどこまで均せるかを比較する。

これは「等角予測の欠陥」ではない。周辺被覆しか約束していないのだから仕様どおりである。
そして Barber et al. (2021) により、分布に仮定を置かない限り条件付き被覆は
**原理的に達成できない**。第3章6節の理論と対応させて論じること。

## データ生成過程

`src/conformal/datasets.py: heteroscedastic`

    X ~ Uniform(0,1)^5
    Y = X1 + sin(2*pi*X2) + sigma(X1) * N(0,1)
    sigma(x) = 0.1 + 1.0 * x        <- X1 が大きいほど誤差が大きい

## 手続き

1. 学習用データで以下の3通りを用意する
   - (a) 絶対残差スコア（下敷き：勾配ブースティング）
   - (b) 正規化残差スコア（残差の絶対値を別に回帰して sigma(x) を推定）
   - (c) CQR（分位点回帰を alpha/2, 1-alpha/2 で学習）
2. 較正集合 n=1000 で共形分位点を求める
3. テスト集合で、周辺被覆率・平均幅・**X1 の5分位で層別した被覆率**・SSC を測る
4. 試行 500 回

## 出力

`results/e3_conditional.csv` : 列 = [method, trial, bin, n, coverage, mean_width]

## 検証（この実験が正しく走ったと判断する基準）

- 3手法すべてで**周辺被覆率は `1-alpha` を満たす**（ここが崩れたら実装ミス）
- (a) では **X1 の層別被覆が大きく割れる**（低い層で過剰、高い層で不足）
- (b)(c) では層別被覆のばらつきが明確に縮む。**最悪層の被覆率**で比較する
- (c) の区間幅が X1 に応じて広がる（適応的である）

## 図（本論文の顔になる2枚）

1. **帯グラフ**：横軸 X1、縦軸 Y。予測区間の上下限を帯で描き、実データ点を重ねる。
   (a) は幅が一定、(c) は X1 とともに広がる。**この対比が一目で分かる図**にする
2. **層別被覆の棒グラフ**：X1 の5分位ごとの被覆率。名目値に水平線。

## 考察に書くこと

周辺被覆という保証は守られている。破綻しているのは「どの集団でも同じ精度で当たってほしい」
という**我々の期待**の方である。実務では部分集団ごとの妥当性が問われる場面が多く、
その意味でこの限界は本質的である。そして不可能性定理により、分布フリーの枠組みに
とどまる限り、これは近似的にしか改善できない。
