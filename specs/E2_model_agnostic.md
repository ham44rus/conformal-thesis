# E2: 下敷きモデルへの非依存性

対応：卒論 第5章 5.6節 ／ 実装 `experiments/e2_model_agnostic.py`

## 目的

**被覆率は下敷きモデルによらず一定であり、区間の幅だけがモデルの精度に応じて変わる。**
この対比そのものを示す。等角予測の中心的な主張の実証にあたる。

## データ生成過程

`src/conformal/datasets.py: homoscedastic`（**E1と同一**）

    X ~ Uniform(0,1)^5
    Y = X1 + sin(2*pi*X2) + N(0, 0.5^2)

E1と同じDGPを使うのは、E1の結果と直接比較できるようにするため。
この設定には `sin(2*pi*X2)` があるので線形モデルには誤特定が入り、
非線形モデルとの精度差が自然に生じる。**追加のDGPは用意しない。**

## 下敷きモデル（5種）

すべて scikit-learn。CLAUDE.md の依存パッケージ制限内。

| キー | モデル | 内部乱数 |
|---|---|---|
| `constant` | 定数予測器（学習データの y の平均を常に返す） | なし |
| `ridge` | `Ridge(alpha=1.0)`（E1と同一） | なし |
| `rf` | `RandomForestRegressor(n_estimators=200)` | あり |
| `gbm` | `GradientBoostingRegressor()` | あり |
| `mlp` | `MLPRegressor(hidden_layer_sizes=(64, 64), max_iter=2000)` | あり |

`constant` は**必ず含める**。「最悪のモデルでも被覆する」というモデル非依存性の主張が
最も強く出るため。（`tests/test_coverage_theory.py::test_最悪のモデルでも被覆する` は
リーク検出が目的の単体テストであり、こちらは第5章に載せる実験結果。役割が違うので両方置く。）

## 手続き

**試行ごとに引き直すのは較正集合のみ。学習集合とモデルは全試行で固定する。**（E1と同じ方針）

理由：E2が示したいのは「与えられたモデルに対して被覆が成り立つ」ことなので、
学習の変動を混ぜると被覆率の分布がBetaからずれ、E1との接続が切れる。
また幅の比較も、モデルの差か学習の運かが分離できなくなる。

1. 学習集合 500 点を1回だけ生成し、**5モデルすべてが同じ学習集合を使う**
2. 各モデルについて、テスト集合 200,000 点の絶対残差を計算してソートしておく
   （被覆率は `searchsorted(sorted_res, q) / N` で評価する。テスト集合はモデルごとに
   同じ点集合を使い、残差だけモデルごとに持つ）
3. 試行 r = 1..1000：
   a. 較正集合 500 点を新規生成する（**5モデルで同じ較正集合を共有する**。
      モデル間の差からサンプリング変動を除くため）
   b. 各モデルについて絶対残差スコアから `q` を求め、被覆率と幅 `2q` を記録する
4. `alpha = 0.10` に固定

### 乱数の扱い

再現性ルール（同じ seed で2回実行したら csv が完全一致）を満たすため、
内部乱数を持つモデルの `random_state` は `--seed` から決定的に導出する。

    rng = np.random.default_rng(seed)
    model_seeds = {key: int(rng.integers(0, 2**31 - 1)) for key in MODEL_KEYS}

`MODEL_KEYS` は上表の順で固定する（順序が変わると seed が変わるため）。
データ生成にも同じ `rng` を使い、生成順を固定する。

### 頑健性の確認（主分析の後に行う）

主分析は学習集合1つに条件づいた結果なので、幅の順序が学習の運で決まっていないことを確認する。

- 学習集合と `random_state` を5通り（`train_rep = 0..4`）振り、各200試行だけ回す
- **幅のモデル間順位が5通りすべてで一致すること**を確認する
- 結果は `results/e2_robustness.csv` に出す

細部（実装時に確定）：

- **乱数の導出**：主分析と同じ `rng` の流れを続けて使う。順序は
  `rep_seeds` → 学習集合 の順で引く。1本の流れなので同一 seed で再現する
- **テスト集合**：主分析と同じテスト点を使い回す。学習集合が変われば残差は変わるので、
  点まで引き直す必要はない
- **`width_rank` の向き**：幅の昇順で `1` = 最も狭い

## 出力

`results/e2_model_agnostic.csv`
: 列 = `[model, trial, coverage, width]`

`results/e2_summary.csv`
: 列 = `[model, coverage_mean, coverage_se, coverage_ci_lo, coverage_ci_hi,
         width_mean, width_se, test_rmse, test_q90_abs_resid]`
: `coverage_se` は**試行間**の標準偏差 / sqrt(R)。
  `test_q90_abs_resid` はテスト集合における絶対残差の 0.90 分位点

`results/e2_robustness.csv`
: 列 = `[train_rep, model, coverage_mean, width_mean, width_rank]`

> **注意：Clopper–Pearson は使わない。** あれは1試行内でテスト点を二項標本とみなす区間であり、
> ここで問題になるのは試行間（較正集合の引き直し）のばらつきである。
> 試行平均の信頼区間は `平均 ± 1.96 × 試行間標準偏差 / sqrt(R)` で作る。

## 検証（この実験が正しく走ったと判断する基準）

すべて実行後に自動判定して表示すること。

**C1｜被覆はモデルによらない**

- 各モデルの平均被覆率が `[1-alpha, 1-alpha + 1/(n_cal+1)]` に、±2×SE の許容で入る
- **モデル間の平均被覆率の最大差が `1/(n_cal+1)` （= 1/501 ≒ 0.0020）より小さい**
  → 理論の上下界の幅そのものを基準にする。モデル間の差がその帯より小さければ
  「被覆はモデルによらない」と言ってよい

**C2｜幅はモデルの精度に依存する**

- `test_rmse` の順位と `width_mean` の順位の**Spearman順位相関が 1.0**
- 隣接する順位のモデル間で `width_mean` の95%CIが重ならない
  → 重なるペアがあれば失敗ではなく、**そのペアは幅で区別できないと報告する**

> 幅は残差の分位点、RMSEは二乗平均なので、裾の形が違えば順序が入れ替わりうる。
> そのため `test_q90_abs_resid`（= 幅の理論的な対応物）との順位相関も併せて出す。
> こちらは 1.0 になるはずで、ならなければ実装を疑う。

> **重要な注意：C2 の信頼区間は学習集合1つに条件づいている。**
> あの区間が測っているのは較正集合の引き直しによるばらつきだけであり、
> 学習集合を引き直したときのばらつきは含まれていない。
> したがって「C2 で分離した」は「**この学習集合のもとでは**幅が違う」という主張にとどまる。
> 学習集合を超えて言えるかどうかは C4 で確かめる。**C2 と C4 は別の問いに答えている。**
>
> これは本論文の中心主題（保証は周辺被覆であって条件付き被覆ではない）と同じ構造である。
> 第5章でこの対応に触れること。

**C3｜定数予測器でも被覆する**

- `constant` の平均被覆率が `1-alpha` 以上。下回ればデータリークを疑う

**C4｜頑健性（学習集合を超えて言えるか）**

- `e2_robustness.csv` で `width_rank` が5つの `train_rep` すべてで一致する
- **一致しなかった場合は失敗ではない。** 以下を追加で判定し、層構造として報告する：
  1. モデルごとに rep 間の平均・SD を出す
  2. 全ペアについて対応あり t 検定（rep をペアとする、自由度4）
  3. **10ペアの多重比較なので、有意水準は Bonferroni 補正して 0.05/10 = 0.005 で判定する**
  4. 区別できるペアと区別できないペアで**モデルを層に分け**、層の境界を報告する
  → 第5章には「幅は層に分かれる。層間は学習集合によらず安定、層内は本実験では区別できない」
     と書く。**これは C4 が通るより情報量の多い結果である**（実験の分解能が分かるため）

## 考察に書くこと

被覆が保証されていても実用的とは限らない。定数予測器は被覆率 0.90 を完全に満たすが、
区間幅は使い物にならない。**保証は「正しさ」であって「有用性」ではない。**

モデル選択は被覆の妥当性には影響せず、区間の情報量にのみ影響する。
これは実務上重要な含意を持つ：**予測モデルの改善努力は、区間の妥当性ではなく
区間の狭さに効く。**
