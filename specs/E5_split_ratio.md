# E5: 学習／較正の分割比

対応：卒論 第5章 E5 の節（`sec:e5`）／ 実装 `experiments/e5_split_ratio.py`

## 目的

データの総数を固定し、学習用と較正用に分ける比を変えたときに、被覆率のばらつき・区間の幅・
予測モデルの精度がどう変わるか（トレードオフ）を測る。

---

## 著者と PM の決定（2026-10-15）

著者の決定：

1. データは**等分散**（`src/conformal/datasets.py: homoscedastic`、E1・E2 と同じ）。
2. 予測モデルは**勾配ブースティング 1 つ**（`GradientBoostingRegressor`、scikit-learn の既定値）。

PM の決定（著者に報告済み）：

1. 総数 1,000 点、較正用の割合を 10〜50% の 5 通り。
2. **試行ごとに学習用も較正用も引き直す。** 比べたいのは学習用の量なので、1 回の学習の出来に
   結果が左右されないようにするため。E1〜E4 は学習済みモデルを固定していたが、E5 は違う。
3. 5 つの割合で**同じデータ・同じ並べ替え**を使う（割合どうしの比較を対にして、データの引き方の違いを除く）。

---

## 理論

学習用データを固定したときの被覆率は Beta(k, n+1−k) に従う（`thm:cond-coverage-beta`。
n は較正用の点数、`k = ceil((n+1)(1-alpha))`、`eq:khat`）。この分布は学習用データによらないので、
学習用データを引き直しても被覆率は同じ Beta(k, n+1−k) に従う。平均は k/(n+1)（`cor:upper`）。

    beta_mean = k / (n+1)
    beta_sd   = sqrt( k (n+1-k) / ((n+1)^2 (n+2)) )

## 手続き

1. `np.random.default_rng(seed)` を作る。
2. テスト集合 100,000 点を `homoscedastic` で 1 回だけ生成する。
3. 試行ごとに、`homoscedastic` で 1,000 点を生成し、0..999 のランダムな並べ替えを 1 つ引く。
4. 5 つの割合で同じデータと同じ並べ替えを使い、並べ替えた先頭の `n_train` 点を学習用、残りの `n_cal` 点を
   較正用にする。**学習用と較正用は重ならない**（スクリプト内の `assert` で確かめる）。
5. 割合ごとに `GradientBoostingRegressor`（既定値。`random_state` は試行ごとに rng から 1 つ引き、
   5 つの割合で共有する）を学習用で学習し、較正用の絶対残差（`eq:score`）から
   `conformal_quantile`（`k = ceil((n_cal+1)(1-alpha))`、`eq:khat`）で `q_hat` を求める。
6. テスト集合で、被覆率、区間の幅 `2*q_hat`、予測モデルのテスト平均二乗誤差 `test_mse` を記録する。

### 乱数の導出

`np.random.default_rng(seed)` の 1 本の乱数列から、次の順に引く（順序は変えないこと）。

1. テスト集合 100,000 点
2. 試行 0, 1, …, 499 の順に、試行ごとに
   1. データ 1,000 点
   2. 0..999 の並べ替え 1 つ
   3. 予測モデルの `random_state`（整数を 1 つ。5 つの割合で共有）

## 出力

- `results/e5_trials.csv` : 列 = `trial, cal_frac, n_train, n_cal, k, q_hat, coverage, width, test_mse`
  （500 試行 × 5 割合 = 2,500 行）
- `results/e5_summary.csv` : 列 = `cal_frac, n_train, n_cal, k, alpha, n_trial, n_test, coverage_mean,
  coverage_sd, beta_mean, beta_sd, sd_ratio, se_trial, se_test, se_total, ci_lo, ci_hi, width_mean,
  width_sd, test_mse_mean, test_mse_sd`（5 行）

    sd_ratio = coverage_sd / beta_sd
    se_trial = coverage_sd / sqrt(R)
    se_test  = sqrt(p(1-p) / N_test)          p = coverage_mean
    se_total = sqrt(se_trial^2 + se_test^2)
    ci_lo, ci_hi = coverage_mean ± 1.96 * se_total

被覆率の標準誤差は、試行間とテスト集合間の 2 成分を合成する（CLAUDE.md「報告の作法」）。
テスト集合を全試行で共有しているので、その集合に固有のずれは試行数を増やしても消えない。

## 検証（この実験が正しく走ったと判断する基準）

**基準は実行前に決めた。結果を見てから変えない。** 満たさなかった場合は、基準を変えずに
事実を「実行結果」に書く。

- **V1（平均）**：すべての割合で `|coverage_mean - beta_mean| <= 3*se_total`。
- **V2（ばらつきの理論との一致）**：すべての割合で `0.90 <= sd_ratio <= 1.10`
  （R=500 での SD の推定の相対誤差は約 3%。テスト集合の有限性による上乗せはこの規模では 1% 未満）。
- **V3（ばらつきの減少）**：`coverage_sd` は `n_cal` について単調に減少する。
- **V4（モデルの精度）**：`test_mse_mean` は `n_train` が減るほど（`cal_frac` が増えるほど）単調に増加する。
- 幅 `width_mean` は合否の基準にせず、数値を報告する。
