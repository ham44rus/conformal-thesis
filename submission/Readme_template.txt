2. 実行手順
----------------------------------------------------------------
[環境]
  Python 3.11
  numpy, scipy, scikit-learn, pandas, matplotlib
  （バージョンは pyproject.toml に記載）

[準備]
  pip install -e .

[実験の実行]
  python experiments/e1_coverage.py --seed 20260901
    -> results/e1_coverage.csv, results/e1_summary.csv が出力される
    -> 所要時間 約10秒

[図の再生成]
  python experiments/make_figures.py
    -> figures/*.pdf, figures/*.png が出力される

[実装の検証テスト]
  pytest
    -> 全テストが PASS することを確認する
    -> 所要時間 約1分

すべて --seed を指定しており、同じ seed で再実行すれば同じ結果が得られる。
