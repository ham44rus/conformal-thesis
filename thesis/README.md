# thesis/ — 卒業論文本文

## ここに置くもの

- `R08_<Name>.tex` … 卒論本文。**先生配布の卒論フォーマットを土台にすること**
- `refs.bib` … 参考文献（作成済み）
- `fig/` … 図。`figures/` から必要なものをコピーするか、相対パスで参照する

## 提出要件（`docs/提出要件と締切.md` より）

提出するのは **TeX・bib・画像（eps または pdf）の3種類のみ**。
コンパイル済み pdf は提出不要。

**受け付けてもらえない条件：**

- `There were undefined references.` が残っている
- 参考文献に `\bibitem` を使っている（**pbibtex での処理が必須**）
- pbibtex で Warning が出ている

## コンパイル確認（提出前に必ず）

```
platex   R08_<Name>
pbibtex  R08_<Name>
platex   R08_<Name>
platex   R08_<Name>
dvipdfmx R08_<Name>
```

`.log` を開いて `undefined` と `Warning` を検索し、1件も無いことを確認する。
