# 本文で採用すべき定義（実装とテストから読み取ったもの）

第3章を書くときの参照用。**src/ と tests/ が実際に固定している定義・記法**を
箇条書きにした。証明や証明の方針は含めない（本文で自力で書く）。

出どころ：`src/conformal/split.py`, `src/conformal/scores.py`, `src/conformal/metrics.py`,
`tests/test_quantile_index.py`, `tests/test_coverage_theory.py`, `tests/test_ties_discrete.py`

コードの docstring が参照している式番号（式(3.3)〜(3.7)、補題3.1、定理3.2、定理3.3）は
現時点の仮番号。本文で番号を確定したら docstring 側を合わせること（付録Aの対応表のため）。

## 1. データ分割と記法

- 学習集合 $\mathcal{D}_{\mathrm{tr}}$ と較正集合 $\mathcal{D}_{\mathrm{cal}} = \{(X_i, Y_i)\}_{i=1}^{n}$ は互いに素。
  **$n$ は較正集合のサイズ**（学習集合のサイズではない）。
- 予測器 $\hat f$ は $\mathcal{D}_{\mathrm{tr}}$ のみから学習し、以後は固定して扱う。
- 新しい点は $(X_{n+1}, Y_{n+1})$。較正集合と合わせた $n+1$ 個が交換可能であることを仮定する。
- TeX 側のマクロは `R08_NAME.tex` のプリアンブルに定義済み：
  `\Dtr`, `\Dcal`, `\fhat`, `\qhat`, `\Prob`, `\Exp`, `\Ind`。

## 2. 非適合度スコア（第3章で使うのは絶対残差のみ）

- $S_i = |Y_i - \hat f(X_i)|,\quad i = 1, \dots, n+1$ 　（式(3.3)）
- 正規化残差・CQR は第4章。第3章の定理は「スコア $S_i$ が交換可能」という形で述べれば、
  スコアの種類によらず使い回せる（コードもそう作ってある：`conformal_quantile` はスコアの
  由来を知らない）。

## 3. 順序統計量の記法

- $S_{(1)} \le S_{(2)} \le \cdots \le S_{(n)}$ を較正スコア $S_1, \dots, S_n$ の**昇順**の順序統計量とする。
- 添字は 1 始まり。コードでは `np.sort(scores)[k - 1]` が $S_{(k)}$ に対応する。
- 同点があっても $S_{(k)}$ は「昇順に並べた $k$ 番目の値」として一意に定まる（並べ方の任意性は値に影響しない）。

## 4. 共形分位点の定義（最重要・式(3.4)）

- $$k = \left\lceil (n+1)(1-\alpha) \right\rceil$$
- $$\hat q = \begin{cases} S_{(k)} & (k \le n) \\ +\infty & (k > n) \end{cases}$$
- **$(n+1)$ であって $n$ ではない。** $\lceil n(1-\alpha) \rceil$ は別物で、テストが弾く
  （$n=20,\ \alpha=0.05$ で $k=20$ vs $19$ に分かれる）。
- **線形補間をしない。** `np.quantile` の既定値とは一致しない（一致したら誤り）。
- 数値例（`test_quantile_index.py` が固定している値）：
  - $n=9,\ \alpha=0.1$：$k = \lceil 9.0 \rceil = 9$、$\hat q = S_{(9)}$（最大値）
  - $n=9,\ \alpha=0.2$：$k = \lceil 8.0 \rceil = 8$、$\hat q = S_{(8)}$
  - $n=8,\ \alpha=0.1$：$k = \lceil 8.1 \rceil = 9 > 8$、$\hat q = +\infty$

## 5. $k > n$ の扱い（$n$ が小さいとき）

- $k > n$ のとき $\hat q = +\infty$ とし、予測区間は $(-\infty, +\infty)$ になる（実装は
  `np.inf` をそのまま返し、区間は `pred ± inf`）。
- これは**バグではなく定義の一部**。本文では「$\hat q = +\infty$ を許す」と定義の中に明記する。
- $\hat q$ が有限になる条件：$k \le n \iff n \ge \lceil 1/\alpha \rceil - 1$。
  例：$\alpha = 0.1$ なら $n \ge 9$、$\alpha = 0.05$ なら $n \ge 19$、$\alpha = 0.2$ なら $n \ge 4$。
- $\alpha$ を小さくすると $\hat q$ は単調非減少（区間は狭くならない）。テストが固定している性質。

## 6. 予測区間と被覆の事象（式(3.5)）

- $$C(X_{n+1}) = \left[\hat f(X_{n+1}) - \hat q,\ \hat f(X_{n+1}) + \hat q\right]$$
- **閉区間**。被覆の事象は $Y_{n+1} \in C(X_{n+1})$、すなわち
  $$\{\,Y_{n+1} \in C(X_{n+1})\,\} = \{\,S_{n+1} \le \hat q\,\}$$
  で、不等号は **$\le$（等号を含む）**。コードも `(y >= lo) & (y <= hi)` および
  `new <= q` で統一している。
- 本文で不等号の向き・等号の有無を変えないこと（同点の扱いと連動する）。

## 7. 共形 p 値の定義（式(3.7)）

- $$p = \frac{1 + \#\{\, i \in \{1,\dots,n\} : S_i \ge S_{n+1} \,\}}{n+1}$$
- 分子の不等号は **$\ge$（等号を含む）**。同点は「新しい点と同じかそれ以上に非適合」として数える。
- 値域は $\{\tfrac{1}{n+1}, \tfrac{2}{n+1}, \dots, 1\}$。

## 8. 同点（離散スコア）の扱い

- **同点はランダム化しない。** 順位付けにも乱数を使わない。定義は上の 3・4・6・7 のとおり
  $\le$ / $\ge$ で固定し、それ以上の処理はしない。
- 定理を述べるときは、次の2種類の主張を**区別して**書く（テストがこの区別を固定している）：
  - 下界 $1-\alpha \le \Prob(Y_{n+1} \in C(X_{n+1}))$ は、**同点の有無によらず**成り立つ主張として述べる。
    仮定は交換可能性のみ。
  - 上界 $\Prob(Y_{n+1} \in C(X_{n+1})) \le 1-\alpha + \tfrac{1}{n+1}$ は、
    **「スコアに同点がほとんど確実に無い」（例：スコアの分布が連続）を追加の仮定**として述べる。
    離散スコアではこの上界は成り立たない（`test_ties_discrete.py` が、水準数 2・3 の離散スコアで
    上界を超えることを固定している）。
- p 値の側での言い換え：同点があっても $\Prob(p \le \alpha) \le \alpha$（超一様性）は保たれる。
  同点が無ければ $p$ は $\{\tfrac{1}{n+1}, \dots, 1\}$ 上の離散一様分布に従う（補題3.1として参照されている）。

## 9. テストが固定している数値的主張（本文で証明するもの）

証明の方針は書かない。**何を主張として書くべきか**の一覧。

| 主張 | 仮定 | テスト |
|---|---|---|
| $\Prob(Y_{n+1} \in C(X_{n+1})) \ge 1-\alpha$ | 交換可能性 | `test_有限標本の上下界`, `test_同点があっても下界は保たれる`, `test_最悪のモデルでも被覆する` |
| $\Prob(Y_{n+1} \in C(X_{n+1})) \le 1-\alpha + \tfrac{1}{n+1}$ | 交換可能性 ＋ 同点なし | `test_有限標本の上下界`, `test_連続スコアでは上下界の両方が成り立つ` |
| 同点なしのとき $\Prob(Y_{n+1} \in C(X_{n+1})) = \tfrac{k}{n+1}$ | 交換可能性 ＋ 同点なし | `test_連続スコアでは上下界の両方が成り立つ` |
| $p$ は $\{\tfrac{1}{n+1},\dots,1\}$ 上の離散一様 | 交換可能性 ＋ 同点なし | `test_共形p値が離散一様分布に従う` |
| $\Prob(p \le \alpha) \le \alpha$ | 交換可能性 | `test_共形p値は同点があっても超一様` |
| 較正集合を固定した被覆率 $\Prob(Y_{n+1} \in C(X_{n+1}) \mid \mathcal{D}_{\mathrm{cal}}) \sim \mathrm{Beta}(n+1-l,\ l)$, $l = \lfloor (n+1)\alpha \rfloor$ | i.i.d. ＋ 同点なし | `test_被覆率がBeta分布に従う` |

- 下界は $\hat f$ の良し悪しによらず成り立つ（定数予測器でも）ことを注意として添えると、
  第5章の E2（モデル非依存性）に直結する。
- Beta 分布のパラメータは $l = \lfloor (n+1)\alpha \rfloor$ で書く。
  $k = \lceil (n+1)(1-\alpha) \rceil$ との関係は $k = n + 1 - l$（切り上げ・切り捨ての定義から従う恒等式）。
  本文ではどちらか一方の記号に統一すること。

## 10. 本文で使ってはいけない書き方（レビューで差し戻される）

- 「$\hat q$ を残差の $(1-\alpha)$ 分位点とする」——線形補間版と区別がつかない。必ず順序統計量で書く。
- 「$\lceil n(1-\alpha) \rceil$」——off-by-one。
- 上界を仮定なしで書く——同点があると破れる。
- 「被覆率 $\approx 1-\alpha$」のように点推定だけで書く——第5章の報告規約（CLAUDE.md 4）に反する。
