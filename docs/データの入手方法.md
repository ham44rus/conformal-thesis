# データの入手方法（提出物 03）

対応：卒論 第6章 実データ解析（`sec:real-data`）／ 実験 E7（`specs/E7_real_data.md`、`experiments/e7_real_data.py`）

実験 E7 は UCI Machine Learning Repository の公開データ 3 件を使う。
データ本体はリポジトリに入れない（`data/raw/` は `.gitignore` 済み）。以下の手順で各自ダウンロードする。
入手日：2026-10-17。

## 一覧

| データ | UCI のページ | zip の URL | ライセンス | 大きさ | sha256 |
|---|---|---|---|---|---|
| Airfoil Self-Noise（UCI 291） | https://archive.ics.uci.edu/dataset/291/airfoil+self+noise | https://archive.ics.uci.edu/static/public/291/airfoil+self+noise.zip | CC BY 4.0 | 60,126 B | `5c7767ba53ad827d3f48ba1eb9434117f4892df8f10bc4c99e118a9e8a7ae07c` |
| Superconductivity（UCI 464） | https://archive.ics.uci.edu/dataset/464/superconductivty+data | https://archive.ics.uci.edu/static/public/464/superconductivty+data.zip | CC BY 4.0 | 8,300,005 B | `87f4490d73390ff94ee01dbf0d7d32abc80b22f2c803d471765cfc46a9f6371e` |
| Bike Sharing（UCI 275） | https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset | https://archive.ics.uci.edu/static/public/275/bike+sharing+dataset.zip | CC BY 4.0 | 279,992 B | `b70182d0d0508e9abbb79306ce5c0cec34869000f8220175ac83d11dbe845401` |

（Superconductivity の URL の `superconductivty` は UCI 側の綴りのまま。）

## 置き場所

zip は展開せず、そのまま次の場所に置く。実験スクリプトは zip から直接読む。

| データ | 置き場所 | zip の中身（使うもの） |
|---|---|---|
| Airfoil Self-Noise | `data/raw/airfoil/airfoil.zip` | `airfoil_self_noise.dat` |
| Superconductivity | `data/raw/superconductivity/superconductivity.zip` | `train.csv`（`unique_m.csv` は使わない） |
| Bike Sharing | `data/raw/bike/bike.zip` | `hour.csv`（`day.csv`・`Readme.txt` は使わない） |

## ダウンロードのコマンド例

リポジトリの直下で実行する。

```sh
mkdir -p data/raw/airfoil data/raw/superconductivity data/raw/bike
curl -L -o data/raw/airfoil/airfoil.zip \
  "https://archive.ics.uci.edu/static/public/291/airfoil+self+noise.zip"
curl -L -o data/raw/superconductivity/superconductivity.zip \
  "https://archive.ics.uci.edu/static/public/464/superconductivty+data.zip"
curl -L -o data/raw/bike/bike.zip \
  "https://archive.ics.uci.edu/static/public/275/bike+sharing+dataset.zip"
```

## 確認

ダウンロード後、sha256 が上の表と一致することを確かめる（Windows なら `certutil -hashfile <ファイル> SHA256`）。

```sh
shasum -a 256 data/raw/*/*.zip
```

`experiments/e7_real_data.py` も読み込む前に sha256 を照合し、一致しなければ止まる。
UCI 側でファイルが差し替えられて一致しない場合は、結果が再現しない可能性があるので、そのまま実験を進めないこと。
